### 🎯 Database rows now work like regular pages

Database row pages are easier to organize, reference, and share across your workspace. You can now:

- Mention a database row page elsewhere in your workspace with `@`.
- Share it directly with other people.
- Add it to Favorites for quick access.
- Recover deleted row pages from Trash.

### 🚀 Quality-of-life improvements

- Drag and drop database view tabs to reorder them.
- Select multiple blocks, then drag and drop them together to another location.

### 🔔 Self-hosted AI

Use AppFlowy AI with on-premises Qwen models and custom embedding models. This is available on the One, Team, and Enterprise self-hosted plans.

### 📝 Faster, more reliable syncing

This release includes major technical changes to how pages are retrieved and synced. They make cloud syncing more reliable and let you configure each collaborator’s permissions on an individual page as **Can View**, **Can Edit**, or **Full Access**.

We also improved syncing speed across devices and fixed platform-specific syncing issues on Android and Linux.

See the [complete v0.13.0 feature and bug-fix list](https://appflowy.com/guide/v0-13-0-New-Features-and-Bug-Fixes).

### 🔥 Upcoming releases

- Side Peek mode for database records.
- Database Form view.

### 🛠️ Work in progress

- Space-level granular permissions.
- Database version history.

> **Note for Windows users:** This release uses a newly renewed code-signing certificate. You may temporarily see a Windows SmartScreen “unrecognized app” warning. The app is properly signed and safe. If prompted, select **More info → Run anyway**. The warning will disappear as the certificate builds reputation.
