Hey there,

v0.9.7 is out with exciting updates!

- AppFlowy Web now supports real-time collaborative editing ⚡️
- Mention or assign a person in the desktop and mobile apps 🔔

<Video src='https://www.youtube.com/embed/ERxAzNqH6yE' alt='AppFlowy v0.9.7 new features demo' />

[AppFlowy Web](http://appflowy.com) syncs data from different devices and users in real time

- No need to refresh the browser page
- This applies to the entire AppFlowy web app, including Grid and Kanban

🔔 Mention or assign a person in the desktop and mobile apps

- Use @ or /person to mention a collaborator
- Choose whether to notify the person when mentioning
- Notified people will receive an email about the mention

GPT-5 & GPT-OSS are available in AppFlowy ✨

- Not a big fan of GPT-5? You can also continue to use GPT-4.1 or GPT-4o
- GPT-OSS requires installation via Ollama

More colors 🎨

- The color menu now offers more options and a more intuitive custom color picker
- Expanded page cover, block, and database select color options
- Pro Plan users get even more exclusive color choices

Backing up your AppFlowy Workspace is now easier

- Export your workspace as a ZIP file
- Import it as a new workspace
- Self-hosters can use it to duplicate workspaces with built-in templates

📺 [17 self-hosted video tutorials](https://www.youtube.com/playlist?list=PLqKX5matmbL6CYkAzzF0T_ecoV6JXe_Xv) are now available to watch 👀

Upcoming releases:

- iOS and Android widgets, and third-party app “Share to AppFlowy”
- AppFlowy Web: create and edit calendar views (monthly and weekly 🆕 )

Work in progress:

- Page version history
- Push notifications
- Self-hosted commercial plans

Until next time,

The AppFlowy Team
