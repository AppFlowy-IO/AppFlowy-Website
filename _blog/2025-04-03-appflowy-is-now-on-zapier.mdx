AppFlowy is now on Zapier. Connect AppFlowy with other apps to automate your workflow. Simply visit [https://zapier.com/apps/appflowy/integrations](https://zapier.com/apps/appflowy/integrations) to get started 🥳

<Video src="https://www.youtube.com/embed/vrEJQpyWdRg" alt="AppFlowy is now on Zapier" />

## What is Zapier
[Zapier](https://zapier.com/) is a popular web automation tool that connects different apps and services together without requiring coding knowledge. 

Zapier can save significant time by automating repetitive tasks that would otherwise require manual effort. It also can help improve team productivity by automating routine workflows like data entry and notifications.
## Popular use cases of connecting AppFlowy with other apps on Zapier—no code required

✅ When a new AppFlowy calendar event is created, add a Google Calendar event.

✅ When a Kanban card is updated, send a Slack message to a group channel.

✅ When a new form submission is received from a third-party tool, create a new database record in AppFlowy.

## AppFlowy REST API
