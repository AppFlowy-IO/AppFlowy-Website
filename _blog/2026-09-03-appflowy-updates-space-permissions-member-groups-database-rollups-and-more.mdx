### 🎉 Space-level permissions are here

Control who can view or edit content at the Space level across your AppFlowy workspace. You can:

- Create Groups in **Settings → Members** to manage permissions for multiple members together.
- Create Custom Spaces and control which users and Groups can access them.
- Combine Space-level and page-level permissions for more granular access control.
- Keep a Space restricted while granting specific collaborators or guest editors access to individual pages.

Learn more about [Space-level permissions](https://appflowy.com/guide/space-level-permissions) and [page-level permissions](https://appflowy.com/guide/page-level-permissions).

### 🚀 Database improvements

- **Rollup visualization:** Display Rollup values as a progress bar or ring to track progress visually.
- **Created by:** Automatically see who created each database item.
- **Last edited by:** Automatically see who last modified each database item.
- **Group by Relation:** Group database records by a Relation property.
- **Relations in Database Templates:** Add Relation properties to templates and use them when creating new database records.
